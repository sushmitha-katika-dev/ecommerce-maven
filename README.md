# E-Commerce Maven Application

A console-based E-Commerce backend application built using Core Java and Maven while following layered architecture principles and clean coding practices.

## 🚀 Features

* Customer Signup & Login Authentication
* Product Management Module

  * Add Product
  * Update Product
  * Delete Product
  * View Products
* CSV-based Data Persistence
* Menu-Driven Console Application
* Product Catalog with Pricing & Discounts
* Exception Handling with Custom Exceptions

## 🏗 Architecture

The project follows a layered architecture approach:

```text
UI → Controller → Service → Repository → CSV
```

## 🛠 Tech Stack

## ▶ How to Run

1. Clone the repository

```bash
git clone https://github.com/sushmitha-katika-dev/ecommerce-maven.git
```

2. Open the project in IntelliJ IDEA or any Java IDE

3. Build the project using Maven

```bash
mvn clean install
```

4. Run the application

```bash
mvn exec:java
```
